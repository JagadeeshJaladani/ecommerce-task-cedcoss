# Gotoshop – Referral Program Page

A referral program page built for **Gotoshop** (fictional e-commerce platform) as part of the **Cedcoss Technologies x LPU Placement Drive 2026** (Round 2 Task).

## 🔗 Live Preview
Open `index.html` in any browser.

## 📌 Features
- Unique referral link display for each user
- One-click Copy to Clipboard with visual feedback
- Stats dashboard: Friends Referred, Points Earned, Credits Earned
- Animated counting numbers on page load
- Top 5 Referrers Leaderboard with medals
- WhatsApp and Email share buttons
- Fully responsive design (mobile friendly)

## 🛠️ Tools Used
- HTML5
- CSS3 (Flexbox, Grid, responsive design)
- Vanilla JavaScript (DOM manipulation, Clipboard API)
- Git & GitHub for version control
